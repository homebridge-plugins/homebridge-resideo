Thank you for installing homebridge-resideo

Before continuing:

  1. Login / create a developer account at https://developer.honeywellhome.com/user.
    This is a separate account from the one you use in the Honeywell Home / Resideo app. It is only used to generate the key and secret below.
  2. Click Create New App.
  3. Give your application a name, and enter the 'Callback URL' exactly as it is displayed below.
  4. Enter the generated 'Consumer Key' and 'Consumer Secret' on the next page.
Please enter both values
Config saved, please close this window and restart Homebridge
Which account does the next window want?
Continuing opens a Honeywell/Resideo sign-in window. Sign in there with your Honeywell Home / Resideo app account — the same email and password you use in the phone app to see your thermostats. That is not the developer account you used above, and your browser may try to autofill the wrong one.
If that account will not sign in even though the password is right, use Forgot password in that window and reset it — that has fixed it for others.

Thank you for using homebridge-resideo

Plugin Information
  • This plugin allows you to view and control your Resideo (Honeywell Home) devices within HomeKit. The plugin:
    • requires a (free) Resideo developer account to work - this is separate from the Resideo account you use in the Resideo app
    • connects to the Resideo cloud to discover and control your devices
Prerequisites
  • To use this plugin, you will need to already have:
    • Node: latest version of v22 or v24 - any other major version is not supported.
    • Homebridge: v2 - refer to link for more information and installation instructions.
